# Beauty Shop – Beauty & Cosmetics Landing Page

A responsive, single-page beauty and cosmetics website built with plain HTML, CSS and JavaScript. No frameworks or build tools needed.

## Features

- Sticky header with working navigation (Home, Shop, Skin Care, Makeup, Hair Care, Fragrances, Blog, About Us)
- Hero section, category bar and "Shop By Category" circles
- Category tabs that filter the product grid
- Add to Cart with a live cart counter
- Promo banners, About section with stats, features strip and blog cards
- Newsletter subscribe form with confirmation message
- Mobile-friendly layout with a hamburger menu
- Photos are embedded in the file, so it works offline

## How to Use

1. Download `index.html`.
2. Open it in any modern browser (double-click the file).

## Customising

- **Products and categories:** edit the `cats`, `prods` and `posts` arrays in the `<script>` section at the bottom of `index.html`.
- **Colours:** change the CSS variables in `:root` at the top (`--g`, `--g2`, `--cream`, `--sage`).
- **Fonts:** Playfair Display, Inter and Mrs Saint Delafield are loaded from Google Fonts (internet needed for them; fallback fonts are used offline).
